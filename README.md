# Tim Bunker Portfolio

A Jekyll portfolio with project pages and blog posts.

Project entries live in `_projects/`, posts in `_posts/`, and the site settings in `_config.yml`. Layouts and shared page fragments are in `_layouts/` and `_includes/`.

The repository includes a GitHub Pages workflow. Its configured site is [timothybunker.github.io/TimBunkerPortfolio](https://timothybunker.github.io/TimBunkerPortfolio/).
